高效语义分割——BiSeNetv2的网络设计与训练策略

Created on October 09, 2024

2024   ·   图像分割   图像处理与视觉算法   计算机视觉   ·   项目实践

在语义分割的发展过程中，从 FCN 到 DeepLab 系列，学术界在提升精度方面取得了显著进展。
这些方法在 复杂语义建模 上表现突出，例如 DeepLab 系列利用空洞卷积和多尺度上下文增强了全局建模能力。

然而，当我们尝试将这些模型应用到 工程项目（如自动驾驶、视频监控、AR/VR 等实时场景）时，就会发现它们存在明显的局限性：

  • 计算量大、推理速度慢，难以满足实时需求
  • 单一主干网络难以兼顾两类矛盾任务：
    • 保留高分辨率的空间细节
    • 捕获低分辨率的全局语义
  • 一些改进方案（如跳跃连接、空洞卷积）虽然一定程度缓解了矛盾，但本质上仍属于“修补”，并未从结构上彻底解决问题

正是在这样的背景下，BiSeNetv2 应运而生。它通过 双分支轻量化结构，让不同分支各司其职：

  • 细节分支专注高分辨率空间信息
  • 语义分支聚焦全局上下文特征
    二者在 BGALayer 中高效融合，最终实现了速度与精度的平衡。

这种设计思路不仅具有较强的工程实用性，还符合人类视觉系统的感知习惯：先整体感知语义，再聚焦细节信息。

📌 总体介绍：BiSeNetv2 的设计思路

为了解决上述问题，BiSeNetv2 提出了 双分支结构：

  • 细节分支（Detail Branch）：专注保留高分辨率空间细节信息
  • 语义分支（Semantic Branch）：快速下采样，提取全局语义特征
  • BGALayer：语义引导的特征聚合层，实现细节与语义的高效融合
  • SegmentHead：在训练中辅助监督，提升边界精度，推理阶段可移除

这种 分工协作机制 使 BiSeNetv2 在实时场景下既快又准。

📌 详细结构解析

1. 细节分支（Detail Branch）
  • 三层卷积 → BN → 激活的堆叠结构
  • 输入通道数：3 → 64 → 64 → 128
  • 输出特征图分辨率：缩小至 1/8

👉 通过较少次数的下采样，保留边缘、纹理等局部空间细节，更适用于 小目标检测 ，同时 提升边界精度

2. 语义分支（Semantic Branch）
  • 分辨率逐步缩小至1/32，通道数扩展：3 → 128
  • 包含多个高效结构模块：

(1) StemBlock：高效初始下采样

  • 左路径：卷积下采样（学习抽象特征）
  • 右路径：最大池化（保留显著特征）
  • 二者融合，兼顾细节与抽象表达

(2) GELayerS2：带残差的 2 倍下采样层

  • 主路径：卷积 → 深度可分离卷积下采样 → 特征增强 → 压缩
  • 残差路径：深度下采样 + 通道调整
  • 融合残差连接的下采样策略，既保证下采样效率，又避免语义特征流失

(3) GELayerS1：特征增强层（不改变分辨率）

  • 深度可分离卷积提升表达
  • 残差结构保证稳定性
  • 在保持分辨率的同时强化语义抽象能力

(4) CEBlock：全局上下文建模

  • 全局平均池化（GAP）提取通道全局信息
  • 通道注意力机制增强全局依赖建模
  • 将全局特征通过广播机制回注到每个像素，提升语义一致性

👉 通过逐步下采样和轻量化卷积模块，快速获得 大感受野与全局语义信息，在保证效率的同时实现更强的语义抽象。

3. BGALayer：双分支特征融合
  • 输入：细节分支 H×W×C，语义分支 H/4×W/4×C
  • 语义分支生成两路注意力：一路低分辨率 Sigmoid 权重，一路上采样至高分辨率
  • 高分辨率融合：细节分支与上采样的语义权重点乘，抑制噪声、突出语义一致区域
  • 低分辨率融合：细节分支下采样后与低分辨率语义权重点乘，为语义分支补充细节
  • 两路结果相加，再经过 3×3 卷积 + BN 输出

👉 借助 注意力机制，语义分支对细节分支进行引导，突出目标区域、抑制无关噪声，最终获得既有 局部精细度 又具备 全局一致性 的融合特征。

4. SegmentHead：辅助训练机制
  • 在语义分支的不同阶段接入多个 SegmentHead，各自通过上采样恢复分辨率并计算辅助损失
  • 提供 深监督信号，改善梯度回传；推理阶段可移除，不影响速度

👉 在训练阶段提升 收敛速度、边界精度与模型鲁棒性，而在推理阶段保持轻量化，不增加额外计算开销。

📌 应用价值

BiSeNetv2 的核心创新：

  1. 双分支设计：彻底解决了“细节与语义矛盾”
  2. BGALayer：轻量级注意力融合，实现高效特征交互
  3. 辅助监督机制：训练阶段提升精度，推理不增加负担

✅ 性能优势：

  • 经测试，BiSeNetv2 在保持 接近 DeepLabV3 精度 的同时，推理速度可达 FPS 100+
  • 内存占用显著下降，适合嵌入式与移动端

👉 这使 BiSeNetv2 成为 交通、自动驾驶、实时监控 等场景的代表性高效模型。

一句话总结：BiSeNetv2 通过“分而治之”的结构设计，达成了实时语义分割的平衡解法。

📌 损失函数设计

损失函数 = 主分支交叉熵损失（OHEM） + 辅助分支交叉熵损失（OHEM） + 边界增强损失（BCE + Dice）

BiSeNetv2 在训练阶段采用多目标联合优化机制：

  • 主分支（Main Head）：负责核心语义分割任务，保证全局语义的准确性；
  • 辅助分支（Auxiliary Head）：在不同尺度上提供深监督信号，增强网络对多尺度目标的学习能力；
  • 边界增强损失（Detail Loss）：专注于边缘与细节区域，提升小目标与边界预测的精细度。

这种组合设计使得网络在语义一致性与边界精度之间取得平衡。

OHEM（Online Hard Example Mining）

OHEM 用于主分支与辅助分支的交叉熵损失中，其核心思想是：
不让模型在“容易的像素”上浪费梯度，而是聚焦于那些难以正确分类的样本。

算法流程：

  1. 对每个像素计算交叉熵损失；
  2. 筛选出损失值高于阈值的困难像素；
  3. 若困难样本数量过少，则保留损失最高的 n_min 个像素；
  4. 对选中的困难像素求平均，得到最终的 OHEM Loss。

优势：

  • 聚焦边界区域与小目标，强化模型的区分能力；
  • 提高梯度利用效率，使训练更稳定、更有针对性。

不足：

  • 每次前向传播需要进行筛选与排序，略微增加计算开销。
边界增强损失（BCE + Dice）

在语义分割中，边界模糊与小目标丢失 是常见问题。
BiSeNetv2 通过 BCE + Dice 组合损失 对边界区域进行专项优化，从像素级与整体形状两方面提升预测质量。

标签预处理：

  • 边界提取：
    使用拉普拉斯卷积核对语义标签进行二阶导数计算，提取边缘位置：
    \(\begin{bmatrix} -1 & -1 & -1 \\ -1 & 8 & -1 \\ -1 & -1 & -1 \end{bmatrix}\)

卷积结果反映中心像素与邻域的灰度差异，差值越大表示边界越明显。 将结果中大于 0.1 的像素视为边界，生成初步边界掩码。

  • 多尺度融合：
    对边界掩码分别进行 2、4、8 倍下采样，并使用最近邻插值恢复原尺寸； 将多尺度特征通过卷积加权融合，再经阈值化得到最终的 多尺度边界图。

损失计算：

  • BCE Loss（带数值稳定处理）：像素级监督，确保模型准确识别边界位置；
  • Dice Loss：度量预测与真实边界的重叠比例，优化整体形状一致性与连贯性。

两者互补：BCE 强调像素精度，Dice 注重结构一致性。 这种组合在边界不平衡、目标细小、区域重叠不明显的场景下尤其有效。

✅ 总结：
BiSeNetv2 的损失函数体系通过 “语义主干监督 + 多尺度辅助学习 + 边界精细增强”三重设计，实现了从全局到局部的多层优化。 模型不仅具备良好的语义一致性与鲁棒性，同时在边缘与小目标区域 上也能保持高精度预测。

📌 结语

BiSeNetv2 在语义分割领域提出了一个兼顾速度与精度的解决方案，特别适合 工程落地。
它不仅在学术上有意义，更在实践中启发了我们如何平衡 局部细节与全局语义。
